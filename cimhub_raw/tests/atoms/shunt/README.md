# Shunt atoms (slices R2, R2b)

Hand-built by the CIMHub team in the RAW v34 format; synthetic, no real network. They cover what neither public
case (IEEE14, WECC240) has. Each is the two-bus node-breaker atom's section layout with its own data and no
SUBSTATION data. Generated by a script from that atom; the data rows are listed here.

| atom | content |
|---|---|
| `fixed_shunts.raw` | one 115 kV bus with two fixed shunts: `1` GL + jBL = 1.5 + j20 (in service), `2` BL = -10 (a reactor, out of service) |
| `plant_and_facts.raw` | five 230 kV buses (R2b), from the `generators.raw` frame. Bus 1: a WMOD 1 machine `PV` (QT 50, QB -30). Bus 2: MODSW 3 regulating that plant over VSWLO 0.25 to VSWHI 0.75, 2 x 10. Bus 3: MODSW 3 with no plant (SWREG 0, a type 1 bus), out of service, VSW 0 / 1, 1 x 5. Bus 4: FACTS device `SVC-1`, shunt only, SHMX 100. Bus 5: MODSW 6 regulating `SVC-1` over 0.4 to 0.6, 3 x 20 |
| `switched_shunts.raw` | 230 kV buses 1-3 and 115 kV bus 4. Bus 1: MODSW 1 regulating remote bus 4, a reactor block 2 x -15 then capacitor blocks 3 x 10 and 2 x 25, BINIT -15. Bus 2: MODSW 2 (continuous), 4 x 12.5, BINIT 31.25 (2.5 steps). Bus 3: MODSW 0 (locked), ADJM 1, 10 x 1.0 and 5 x 1.5, BINIT 13 |
