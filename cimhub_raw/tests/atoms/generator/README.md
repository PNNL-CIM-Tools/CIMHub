# Generator atoms (slice R3)

Hand-built by the CIMHub team in the RAW v34 format; synthetic, no real network. They cover what neither public
case (IEEE14, WECC240) has. Each is the two-bus node-breaker atom's section layout with its own data and no
SUBSTATION data. Generated by a script from that atom; the data rows are listed here.

| atom | content |
|---|---|
| `generators.raw` | Area 1; 230 kV buses 1 (IDE 3) and 3 (IDE 1); 13.8 kV buses 2 (IDE 2), 4 (IDE 1) and 5 (IDE 2). Bus 1: a swing machine `1` (ZR + jZX = 0.003 + j0.25 on MBASE 200). Bus 2: a plant regulating remote bus 3 at VS 1.01, machine `G` (WMOD 0, PB -40) and an out-of-service converter `PV` (WMOD 1). Bus 4: a fixed-output machine on an IDE 1 bus (QT = QB = 2). Bus 5: a record of the bus number alone, every other field defaulted (MBASE = SBASE) |
