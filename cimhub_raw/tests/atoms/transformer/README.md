# Transformer atoms (slice R4)

Hand-built by the CIMHub team in the RAW v34 format; synthetic, no real network. They cover what neither public
case (IEEE14, WECC240) has: every public transformer is 2-winding with CW = CZ = CM = 1 and COD 0 or 1. The atom
is the two-bus node-breaker atom's section layout with its own data and no SUBSTATION data. Generated by a script
from that atom; the data rows are listed here.
