# cimhub_core

Shared layer for CIMHub converter spokes: the `.cimtbl` import contract (`cimhub_core.cimtbl`,
`CimtblImporter`), the test harness (`cimhub_core.cimtbl_testing`), the canonical table shapes
(`cimhub_core/shapes/`), and native-model utilities (`GraphModel`, `AnnotationSerializer`).
CIM is cim18v17 only.
